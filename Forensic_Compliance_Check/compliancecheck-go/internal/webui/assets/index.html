Paste text. Checks whether it already reads as a known language, tries every supported cipher (Caesar/ROT13/Atbash/Vigenère) if not, and separately looks for embedded encoded substrings (base64/hex/base32/binary/URL-encoding).

Pick a cipher. Leave the key blank for Caesar or Vigenère and it will attempt to recover the key automatically (brute force for Caesar, cryptanalysis for Vigenère) - useful when you know or suspect the cipher but not the key.

File Hash Calculator

Computes MD5 / SHA-1 / SHA-256 / SHA-512 for a file on this machine - standard integrity verification / fingerprinting.

Hash Identifier

Guesses likely algorithm(s) from a bare hash string's length/format. Not certain by nature (e.g. MD5 and NTLM are both 32 hex chars) - shows every plausible match.

JWT Decoder

Decodes a JWT's header and payload for inspection. Does NOT verify the signature (that needs the signing secret, which this tool never has) - flags alg=none and expired/not-yet-valid tokens.
